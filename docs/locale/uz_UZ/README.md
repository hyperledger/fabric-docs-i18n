# Fabric Docs uz_UZ

A project to translate the Hyperledger Fabric documentation into Uzbek (Latin script).

Hyperledger Fabric hujjatlarini o'zbek tiliga (lotin yozuvida) tarjima qilish loyihasi.

# Scope

The purpose of this project is to translate the Fabric documentation into Uzbek, using the official Uzbek Latin alphabet. We will use this repository to sync with the English version of Hyperledger Fabric, starting with release 2.5.

Ushbu loyihaning maqsadi — Fabric hujjatlarini rasmiy o'zbek lotin alifbosida o'zbek tiliga tarjima qilish. Biz ushbu repozitoriyni Hyperledger Fabric'ning inglizcha versiyasi bilan 2.5 relizidan boshlab sinxronlab boramiz.

The original online documentation is: https://hyperledger-fabric.readthedocs.io/

The Uzbek online documentation is: coming soon...

Asl onlayn hujjatlar: https://hyperledger-fabric.readthedocs.io/

O'zbekcha onlayn hujjatlar: tez orada...
